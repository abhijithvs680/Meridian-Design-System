# DashboardShowcase

A full agent-driven dashboard composed only from Meridian components, following the Dashboard page pattern: app shell, PageHeader, KPI row, insight and approval, then a "Needs attention" table. Resize to see the sidebar collapse to a rail (under 1024px) and hide (under 768px).

## Composition
Sidebar · PageHeader (date range Select, agent Summarize, primary New invoice) · 4 StatCards · InsightCard + ApprovalCard in `.m-grid-2` · DataTable.
