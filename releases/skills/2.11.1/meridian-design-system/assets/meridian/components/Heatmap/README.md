# Heatmap

Activity heatmap (calendar grid) and treemap for density and hierarchy.

## When to use
Activity over days/hours; concentration (which customers make up revenue).

## Anatomy and variants
`.m-heat` grid of 11px cells in 5 levels mixed from `primary`; legend "Less … More". Treemap `.m-treemap` blocks sized by value.

## States
Hover a cell for the exact count and date.

## Accessibility
Provide the data as a table alternative; levels are also in tooltips as numbers.

## OpenUI
`Heatmap(cells) · Treemap(items)`
