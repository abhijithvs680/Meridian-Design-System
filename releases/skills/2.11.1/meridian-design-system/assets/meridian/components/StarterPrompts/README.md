# StarterPrompts

Starter prompts and the "ask your data" entry point: an input plus suggested questions grounded in the user's data.

## When to use
Empty agent panels and workspaces, new users, and the top of data pages.

## Anatomy and variants
Large `.m-input-group` with the sparkle and a solid Send → `.m-prompts` grid of `.m-prompt` buttons (question + what it will do).

## States
Prompts adapt to the page and data; clicking fills and sends.

## Accessibility
Prompts are buttons with full text; the input has a label.

## OpenUI
`StarterPrompts(prompts)`
