# Meridian asset library

Original vector assets authored for this Meridian expansion. No external icon pack, premium download or stock illustration was embedded. The user's existing project ownership remains unchanged; this file does not impose a new redistribution license on the original system.

- `Icons/`: 24 × 24 outline SVGs, 1.75 stroke, rounded caps and joins. Inline the SVG to inherit text color, or use `sprite.svg#name` with `<use>`. External `<img>` icons render their own default color.
- `Illustrations/`: six 320 × 240 orbital scenes for onboarding and empty states. Fixed light brand palette; place on a light inset surface in dark themes.
- `Backgrounds/`: four restrained SVG textures for marketing surfaces.
- `Logos/`: light and dark Meridian marks and a wordmark lockup. These replace missing binary references in the imported archive. The lockup uses a live system-font text element; convert to outlines in a vector editor for exact print reproduction.

Use `alt=""` for decorative images and meaningful alternative text when an image conveys information. Avoid repeating nearby labels. Use only the sparkle icon for agent identity. Keep icons within one consistent family on a screen. See `manifest.json` for paths and collection membership.
