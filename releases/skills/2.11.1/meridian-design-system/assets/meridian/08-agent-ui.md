# Agent UI

How AI agents appear inside business apps and dashboards. The goal: people always know **what the agent did, why, from which data, and what still needs them.**

## The five agent surfaces
| Surface | Component | When |
| --- | --- | --- |
| Conversation | AgentMessage, ChatThread, AIComposer | A user asks a question or delegates a task |
| Progress | AgentRunSteps, AgentTimeline | The agent is working; tool calls in plain language |
| Approval | ApprovalCard | Before any write: send, update, pay, delete |
| Insight | InsightCard | The agent proactively surfaces a finding |
| Status | Badge (agent tone) + pulse | A record is being worked on by an agent |

## Rules
1. **Mark generated content.** Sparkle, `agent` color and a label ("Billing agent", "Agent insight") on everything generated. Computed metrics never use agent styling.
2. **Cite the data.** Every claim from data has a citation chip that opens the source record or query. If the agent can't cite, it says it is estimating.
3. **Show work, then collapse it.** Steps live while running; "4 steps · 9.4s" afterwards.
4. **Read freely, write with consent.** Read tools run automatically. Every write becomes an ApprovalCard with exact parameters; bulk writes show the count and the first few items.
5. **Always stoppable.** A Stop button is visible during every run. A stopped run keeps completed steps and says what didn't happen.
6. **Confidence is explicit.** Insights state High / Medium / Low in words plus the meter, and the data's freshness.
7. **Fail in plain language.** A failed step gets a reason ("Bank feed didn't respond"), what the agent did instead, and Retry. No stack traces; the mono detail may show the tool and error code.
8. **Name the agent, not the model.** "Billing agent", not the LLM's name. One agent per domain keeps responsibility clear.
9. **Keep an audit trail.** Every record an agent touched gets an "Agent log" tab: runs, steps, approvals, who approved and when.

## Agent-driven dashboards
- Layout: KPI row → InsightCards (max 3) and pending approvals → charts → "Needs attention" table.
- "Summarize" / "Ask about this dashboard" opens the agent panel with the current filters as context.
- Agent-generated charts use the same chart component and series colors, inside a Card labelled "Generated by agent" with the query one click away.
- Each card shows "Updated 2 min ago". While an agent recomputes, show skeletons in place; never blank the page.

## Run states
| State | Dot | Badge | Copy |
| --- | --- | --- | --- |
| queued | dashed ring | neutral "Queued" | "Starts after the current run" |
| running | pulsing `agent` | agent "Running" | Present continuous: "Drafting reminders" |
| waiting | `warning` | warning "Needs approval" | "Waiting for your approval" |
| done | `success` check | success "Done" | Past tense: "Drafted 4 reminders" |
| failed | `danger` x | danger "Failed" | Reason + "Retry" |
| stopped | neutral | neutral "Stopped" | "Stopped by you · 2 of 4 steps done" |
