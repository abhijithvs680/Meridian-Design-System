# Meridian Marketing Collection

Open the Marketing section of the workbench for a visual index. Select any section to inspect a live preview, try the viewport presets, and copy its original HTML. The two launch pages show how the sections compose.

Open **Compose a launch page** to choose navigation, a hero, an optional scroll effect, a call to action, and a footer. Download the resulting HTML and save it at the root of your extracted Meridian folder so the relative paths resolve.

## Use in a project

Copy the section markup and load `marketing/marketing.css` inside a `mk-page` wrapper. Include `marketing/marketing.js` for optional interactions. The stylesheet includes paper, ink, forest and rust color scopes. Reference artwork is in `assets/Marketing` as editable SVG. Replace the example navigation destinations and review heading levels after composing sections.

Form specimens validate locally and display feedback. Connect forms to your own service when deploying. Pricing is example content. Scroll effects preserve native document scrolling and provide a static layout for reduced motion and browsers without view timelines. The horizontal gallery also works as a native scroll region.
