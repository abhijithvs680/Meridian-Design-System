# Logos

- `meridian-mark.svg`: the mark, a circle crossed by one meridian arc, in `primary` light (#2e6ae1). Use on light surfaces at 24px in the sidebar, 32px+ elsewhere.
- `meridian-mark-dark.svg`: the same mark in `primary` dark (#71a3ff) for dark surfaces.
- `meridian-lockup.svg`: mark plus "Meridian" wordmark in Inter 600 (`fg` light). Use for login and docs headers.

Clear space around the mark equals its center dot's diameter × 2. Never recolor it to `agent`, add effects, or place it on photos. For a client's white-label build, replace the logo files and the `primary-*` tokens together.
